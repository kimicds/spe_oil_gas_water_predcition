# 🛢️ SPE DSEAT Africa Datathon 2024

## 📌 Overview
The **SPE Data Science and Engineering Analytics Technical Section (DSEAT) Africa Datathon 2024** provides an opportunity for participants to apply **machine learning** to solve real-world challenges in the oil and gas industry.  

The competition focuses on using historical production data to predict **future oil, gas, and water performance** through **multi-output prediction models**.

---

## 🎯 Objective
- Develop a **multi-output machine learning model** to forecast oil, gas, and water production simultaneously.  
- Apply standard ML practices including data preparation, EDA, feature engineering, modeling, and prediction.  

---

## 📂 Dataset
Participants are provided with:  
- **Training dataset**: Historical production records (e.g., production rates, choke sizes, tubing head pressure).  
- **Validation dataset**: To test model forecasts for oil, gas, and water production.  

---

## 📊 Evaluation Metrics
Submissions will be assessed using:  
- **Root Mean Squared Error (RMSE)**  
- **Mean Absolute Error (MAE)**  
- **R² Score** (Coefficient of Determination)
